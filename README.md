# Hybrid movie recommender system

A movie recommendation engine combining **content-based filtering** (tag
similarity) with **collaborative filtering** (SVD matrix factorization) to
produce personalized recommendations — with explicit handling for cold-start
users and a live Streamlit demo.

🔗 **Live demo:**https://hybridrecommender-aubngzcrgqfrkqcyrgbbgu.streamlit.app/

## How it works

1. **Content-based filtering** — Movies are represented as bag-of-words tags
   (overview, genres, keywords, cast, director), vectorized with
   `CountVectorizer`, and compared using cosine similarity.
2. **Collaborative filtering** — An SVD model (`scikit-surprise`) is trained
   on [MovieLens](https://grouplens.org/datasets/movielens/) ratings to learn
   latent user/movie "taste" vectors and predict how a specific user would
   rate any movie.
3. **Hybrid ranking** — For a seed movie, the top 25 content-similar
   candidates are shortlisted (cascade), then re-ranked using a weighted
   blend of content similarity and the user's predicted rating (`alpha`
   controls the blend: 1.0 = pure content, 0.0 = pure collaborative;
   `alpha=0.2` was found to minimize RMSE — see Results below).
4. **Cold-start handling** — two distinct fallbacks, depending on what
   information is actually available:
   - **Has a seed movie, no rating history** (e.g. "more like this" for a new
     user) → falls back to pure content-based similarity, so the result
     stays relevant to what they're looking at.
   - **No seed movie, no rating history** (e.g. a homepage) → falls back to
     an IMDB-style weighted popularity ranking across all users.

## Results

Evaluated on held-out MovieLens test ratings (RMSE / MAE, lower is better):

| Method               | RMSE   | MAE    |
|----------------------|--------|--------|
| Content-based only   | 0.9356 | 0.7240 |
| Collaborative only   | 0.8600 | 0.6624 |
| **Hybrid (alpha=0.2)** | **0.8550** | **0.6594** |

The hybrid model outperforms both individual approaches. `alpha` was tuned by
sweeping values from 0.0–0.5 (see `alpha_sweep.py`) — RMSE improves as
content-based signal is added up to alpha≈0.2, then degrades past alpha≈0.3
as content-based's comparatively weaker signal starts to dominate the blend.
This suggests a *small* amount of content-based information usefully
supplements collaborative filtering's predictions, but shouldn't be weighted
equally with it.

_Generated by `evaluation.py` / `alpha_sweep.py` — see `main.py` for how the
comparison is run._

## Project structure

```
├── app.py                          # Streamlit demo
├── main.py                         # CLI entry point / evaluation runner
├── data_preprocessing.py           # TMDB data cleaning
├── content_based.py                # tag vectorization + cosine similarity
├── collaborative_filtering.py      # MovieLens + SVD training
├── hybrid.py                       # combines content-based + collaborative
├── popularity.py                   # weighted popularity fallback
├── evaluation.py                   # RMSE/MAE comparison across all 3 methods
├── alpha_sweep.py                  # sweeps alpha to find the optimal blend weight
├── data/                           # not tracked in git, see setup below
└── requirements.txt
```

## Setup

```bash
pip install -r requirements.txt
```

Download and place these files in `data/`:
- [TMDB 5000 Movie Dataset](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata) → `tmdb_5000_movies.csv`, `tmdb_5000_credits.csv`
- [MovieLens ml-latest-small](https://grouplens.org/datasets/movielens/) → `ratings.csv`, `links.csv`

## Run

CLI version (prints recommendations + evaluation table to console):
```bash
python main.py
```

Streamlit web app:
```bash
streamlit run app.py
```

## Tech stack

Python, pandas, scikit-learn (CountVectorizer, cosine similarity),
scikit-surprise (SVD), Streamlit
